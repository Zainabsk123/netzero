Core Smart Contract Features
The Project.sol contract includes 3 core functions:

registerUser() - Allows new users to join the platform and track their environmental impact
purchaseCarbonCredits() - Enables users to buy verified carbon offsets from the marketplace
updateEnvironmentalImpact() - Tracks user's carbon footprint changes and rewards improvements

Key Contract Capabilities

User Management: Registration system with carbon footprint tracking
Carbon Credit Marketplace: Secure buying/selling of verified offsets
Reward System: Token incentives for environmental improvements
Impact Tracking: Real-time monitoring of carbon footprint changes
Transparency: All transactions and impacts recorded on blockchain

Additional Features

Owner-controlled credit verification and listing
Comprehensive event logging for transparency
Security modifiers and input validation
Utility functions for data retrieval
Emergency controls for platform management
